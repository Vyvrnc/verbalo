# Contributing

Bug reports and ideas are welcome in the issue tracker. Please say which phone and Android
version you use, and attach the in-app log (History → Log) if something failed.

Before a larger change, open an issue first so we can agree on the approach. Screens follow
[docs/design-language.md](docs/design-language.md); texts go into `res/values*/strings*.xml` in
English and Czech.
